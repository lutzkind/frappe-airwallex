# Support

This is a community project without an Airwallex, Frappe, or ERPNext support entitlement. Use GitHub Discussions for usage questions and GitHub Issues for reproducible defects and feature requests. Security reports must follow SECURITY.md.

Include app/Frappe/ERPNext versions, sanitized configuration, module, dry-run result, and relevant bounded error text. Never include API keys, webhook secrets, account/card IDs, receipt content, production URLs, or private financial data.
