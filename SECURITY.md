# Security Policy

## Supported version

Security fixes are provided for the latest tagged release. Upgrade guidance will be included when a fix changes schema or behavior.

## Reporting

Do not open a public issue for a vulnerability. Use GitHub private vulnerability reporting when enabled, or contact the maintainer through the private channel listed in the repository profile. Include the affected version, impact, reproduction, and suggested mitigation without including live credentials or customer records.

Rotate any credential that may have been exposed before sending a report. Public disclosure should wait until a fix and upgrade path are available.
