# Marketplace preparation

This repository is prepared for a future community marketplace submission but is **not marketplace approved**.

## Publication checklist

- Public repository with GPL-3.0-only license
- Unofficial/community status stated prominently
- Tagged semantic release and changelog
- Supported Frappe/ERPNext versions documented
- Installation, configuration, migration, security, and troubleshooting guides
- Credential-free CI and source package build
- Security policy, support policy, governance, and code of conduct
- Sanitized fixtures and secret scanning
- Screenshots using synthetic companies, accounts, currencies, and transactions
- Review of Airwallex trademark and API-branding requirements
- Review of Frappe/ERPNext marketplace metadata and packaging rules
- Demonstrated fresh install, upgrade, migration, idempotency, and uninstall/rollback behavior
- Native receipt parity or a clearly disclosed compatibility requirement
- Explicit Beta API limitations

## Remaining manual work

Marketplace submission, identity verification, listing assets, screenshots, support commitments, trademark review, and any vendor security questionnaires require a maintainer. Approval must not be claimed before the marketplace operator confirms it.
